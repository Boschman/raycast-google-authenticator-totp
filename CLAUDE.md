# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Raycast extension that lists TOTP profiles from `~/.gauth` and pastes a two-factor code for the
selected one. macOS only. `~/.gauth` is encrypted with sops (binary format) using an age key stored
in the Keychain (service `google-authenticator-totp`, account `age-key`).

## Build

Use the Makefile for everything.

```
make install     # install dependencies (node_modules is gitignored)
make build       # ray build -e dist: compile and type-check
make dev         # ray develop, installs the extension into Raycast for testing
make lint        # ray lint (ESLint + Prettier + manifest and icon validation)
make fix-lint    # ray lint --fix
make clean       # remove node_modules
```

Unlike the sibling extensions, this Makefile does **not** source nvm. Its `check-node` prerequisite
only verifies that the active Node major is at least the version in `.nvmrc` (24), and fails with
`Node 24+ required, found <version>. Run: nvm use` otherwise. Run `nvm use` yourself first.

`node_modules` is a file target depending on `package.json` and `package-lock.json`, so the other
targets reinstall automatically when dependencies change.

`make build` only compiles. Run `make dev` to get changes into the Raycast app.

## Architecture

- **`src/totp.ts`** - decrypts and parses `~/.gauth`, opens it for editing, and generates codes.
  - `sopsEnv` adds Homebrew to `PATH` (Raycast's `PATH` lacks it) and sets `SOPS_AGE_KEY_CMD` to
    read the age key from the Keychain.
  - `getItems()` is **async**: it runs `sops decrypt` and parses the ini-like output with the regex
    `/\[(.*)]\nsecret=(.*)/g` into `{ name, secret }` entries. Note this requires a literal `\n`
    between the header and the secret, so a `\r\n` file will not parse.
  - `editItems()` runs `sops edit` with Sublime Text (`subl --wait`) as `SOPS_EDITOR`, detached so
    it can re-encrypt after the tab closes even if Raycast unloads the command.
  - `getCode(secret)` is **async** and returns the 6-digit code.
- **`src/index.tsx`** - loads the profiles with `usePromise` and renders them as a `<List>`.
  Selecting one generates a code and pastes it via `Clipboard.paste`, then closes the window. The
  "Edit in Sublime Text" action (⌘E) is also available from the empty view.

Codes are generated on demand in the action handler, not at render time, because they expire
every 30 seconds.

## Notes

- **No test suite.** `make build` (type check) and `make lint` are the only verification.
  TOTP output was checked against the RFC 6238 test vectors when `totp-generator` was upgraded.
- `totp-generator` v2 replaced the default-export function with `TOTP.generate(key, options)`,
  which is async and returns `{ otp, expires }`.
- `@raycast/api` v2 supplies `@types/node` and `@types/react`; do not add them to
  `devDependencies`. TypeScript 6 no longer auto-includes `@types`, so `tsconfig.json` lists them
  in `compilerOptions.types`.
- TypeScript is held at 6.x: `@raycast/eslint-config` requires `typescript <6.1.0`.
- `raycast-env.d.ts` is generated by `ray build` and gitignored. Do not edit.
